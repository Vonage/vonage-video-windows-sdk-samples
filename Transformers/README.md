Transformers
==============

Transformers is a simple application meant to get a new developer started using the
Vonage Windows SDK Transformers API. For a full description, see the [Basic tutorial at the Vonage developer
center](https://developer.vonage.com/en/tutorials/basic-video-chat/introduction/windows).

*Important:* To use this application, follow the instructions in the
[Quick Start](../README.md#quick-start) section of the main README file for this repository.

To add transformers follow the guide in https://developer.vonage.com/en/video/guides/media-processor/windows?source=video
